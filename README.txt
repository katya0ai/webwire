WEBWIRE STATIC WEBSITE

Files:
- index.html: website structure and content
- style.css: responsive styling (blue, white and orange palette)
- script.js: mobile navigation and current year
- resources/images/: place the WebWire logo here

LOGO:
Save your logo as:
resources/images/webwire.png

The page currently references that exact path. If your actual logo file is named webwire.pgn, correct the spelling to webwire.png (PNG is the normal image extension), or update the image src in index.html to match the actual filename.

RUN:
Open index.html in a browser. No backend, database or build tools are required.
For local development you can also run:
python3 -m http.server 8000
Then visit http://localhost:8000
